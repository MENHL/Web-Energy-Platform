# GreenGrid 全栈项目启动指南（IntelliJ IDEA 2026.2.1 · 技术小白版）

> 这份文档教你从头到尾把项目跑起来：后端（Spring Boot）+ 前端（Vue）+ 数据库（MySQL）。
> 全程不用懂代码，照着做就行。每一处要点的「在哪里点」都写清楚了。

---

## 0. 这个项目是什么

GreenGrid 新能源运营平台，分三块：

| 部分 | 技术 | 端口 | 说明 |
|---|---|---|---|
| 前端 | Vue 3 + Vite | 5180 | 你在浏览器里看到的界面 |
| 后端 | Spring Boot 3 | 8080 | 处理前端发来的请求，读写数据 |
| 数据库 | MySQL 8 | 3306 | 存数据（项目、设备、物料、用户等） |

三者已经「对接好」：前端请求 → 自动转发到后端 → 后端读写 MySQL。你只要把它们各自启动起来就行。

## 2. 一次性准备：创建数据库

后端启动时会**自动建表 + 写入演示数据**，但那个数据库（容器）要先存在。

用 Navicat 或任意 MySQL 客户端连接 `localhost:3306`（账号 `root` 密码 `root`），执行下面这一句：

```sql
CREATE DATABASE IF NOT EXISTS greengrid_admin DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
```

> 没有 Navicat 也没关系，命令行执行：
> `D:\MySQL\install\bin\mysql.exe -uroot -proot -e "CREATE DATABASE IF NOT EXISTS greengrid_admin DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;"`

**只做这一次。** 之后每次启动后端都会自动把表和演示数据准备好（幂等重建，不破坏你手改的数据以外的种子数据）。

## 3. 启动后端（IntelliJ IDEA）

### 3.1 打开后端项目

1. 打开 IntelliJ IDEA。
2. 菜单栏 `File` → `Open...`。
3. 选中项目里的 `backend` 文件夹（路径类似 `D:\New_xiangmu\New-Energy-Platform\backend`）。
4. 点 `OK`。IDEA 开始加载，右下角会出现进度条，**等它跑完**（首次可能几分钟，在下载依赖，耐心等）。

### 3.2 确认 JDK 是 17

1. 菜单栏 `File` → `Project Structure...`（快捷键 `Ctrl+Alt+Shift+S`）。
2. 左侧选 `Project`。
3. 看 `SDK` 一栏是不是 `17`。
   - 如果已经是 17 → 直接关闭窗口，跳到 3.4。
   - 如果不是 → 点 `SDK` 下拉框 → `Add SDK` → `JDK...` → 选中 `D:\Program\IntelliJ IDEA\JavaJDK` → `OK`。
4. `Language level` 保持默认即可。

### 3.3 确认 Maven 用 IDEA 自带的

1. 菜单栏 `File` → `Settings...`（快捷键 `Ctrl+Alt+S`）。
2. 左侧展开 `Build, Execution, Deployment` → `Build Tools` → `Maven`。
3. 看 `Maven home path`：保持默认（IDEA 自带的那一套即可，通常是 `Bundled (Maven 3)` 或指向 `D:\Program\IntelliJ IDEA\...\maven3`）。
4. 点 `OK`。

### 3.4 运行后端

1. 在 IDEA 左侧项目树里，依次展开：
   `src` → `main` → `java` → `com` → `greengrid` → `admin`。
2. 找到 `GreenGridAdminApplication`（一个 Java 文件）。
3. 双击打开它，点击类名左边的绿色 ▶ 按钮（或右键 → `Run 'GreenGridAdminApplication'`）。
4. 底部「Run」控制台会滚动日志，等它停住。

### 3.5 看到成功标志

当控制台出现下面这行，说明后端启动成功：

```
Tomcat started on port 8080 (http) with context path '/api'
```

### 3.6 验证后端

浏览器打开 `http://localhost:8080/api/swagger-ui.html`，能看到接口文档页面，就是成功了。

## 4. 启动前端（IntelliJ IDEA 终端，或系统命令行）

前端和前端是两个独立项目，前端在**项目根目录**（不是 backend 里）。

### 4.1 打开前端项目

1. 菜单栏 `File` → `Open...`。
2. 选中项目根目录 `D:\New_xiangmu\New-Energy-Platform`（**不是** backend，是它的上一级）。
3. 点 `OK`。也可以开一个新窗口（`New Window`）。

### 4.2 打开 IDEA 内置终端

菜单栏 `View` → `Tool Windows` → `Terminal`（或点底部「Terminal」标签）。

### 4.3 安装依赖（第一次才需要）

在终端里输入并回车：

```bash
npm install
```

看到 `added xxx packages` 之类结束就 OK。

### 4.4 启动前端

在终端里输入并回车：

```bash
npm run dev
```

### 4.5 看到成功标志

终端出现类似：

```
VITE v6.x  ready in xxx ms
  ➜  Local:   http://localhost:5180/
```

## 6. 关键配置在哪（想改的时候看这里）

| 想改什么 | 文件 | 说明 |
|---|---|---|
| 数据库地址 / 账号 / 密码 | `backend/src/main/resources/application-dev.yml` | 默认 `localhost:3306`、`root/root` |
| 后端端口 | `backend/src/main/resources/application.yml` | `server.port: 8080` |
| 前端走真实后端还是假数据 | `.env.development` | `VITE_USE_MOCK=false` 表示走真实后端；改成 `true` 则用假数据演示 |
| 前端代理到后端地址 | `vite.config.ts` | `proxy` 里 `/api` → `http://localhost:8080` |

> 改完配置后要重启对应的进程才生效。

## 7. 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 后端启动报 `Communications link failure` | MySQL 没启动 | 启动 MySQL 服务 |
| 后端报 `Unknown database 'greengrid_admin'` | 没建库 | 回到第 2 步执行建库 SQL |
| 后端报 `Access denied for user 'root'` | 数据库密码不是 root | 改 `application-dev.yml` 的 `password` |
| 后端报 `Port 8080 was already in use` | 端口被占用 | 关掉占用进程，或在 IDEA 里给后端加启动参数 `--server.port=8081` |
| 前端启动报 `npm: command not found` | Node 没装或没进 PATH | 先装 Node.js |
| 前端页面一直转圈、接口报错 | 后端没启动，或 Mock 开关不对 | 确认后端 8080 已起、`.env.development` 是 `VITE_USE_MOCK=false` |
| 登录提示「账号或密码错误」 | 账号密码不对 | 用第 5 节的演示账号 |
| 前端登录后页面空白 | 后端接口异常 | 看后端「Run」控制台的报错日志 |

## 8. 顺序小结（记不住就看这三步）

1. 建库（第 2 步，只做一次）。
2. IDEA 打开 `backend` → 运行 `GreenGridAdminApplication` → 看到 8080 启动成功。
3. IDEA 打开项目根目录 → 终端 `npm install`（首次）→ `npm run dev` → 打开 5180 登录。

前端 api 已通过 `/api` 代理对接到后端，后端再读写 MySQL——整条链路已经打通，无需再改任何代码。
